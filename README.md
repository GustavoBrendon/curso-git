# 🐙 Curso Git

Este repositório reúne materiais e exemplos do curso que realizei para aprender Git, o sistema de controle de versões mais utilizado no desenvolvimento de software.

## 📁 Estrutura do Repositório

- Documentação com comandos Git básicos e avançados
- Exemplos práticos de uso do Git em projetos
- Anotações e dicas para melhor utilização do Git

## 🚀 Tecnologias Utilizadas

- Git (linha de comando)
- GitHub para hospedagem remota dos repositórios

## 📌 Objetivo

Aprender e praticar o uso do Git para controle de versões, colaboração em projetos e gerenciamento eficiente do código fonte.
